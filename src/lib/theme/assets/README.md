# Mona Sans

Official unmodified WOFF2 from github/mona-sans release v2.0.27:
https://raw.githubusercontent.com/github/mona-sans/v2.0.27/fonts/webfonts/variable/MonaSansVF%5Bopsz%2Cwght%5D.woff2

SIL Open Font License: MonaSans-OFL.txt (from the same release).
Axes: weight 200–900 and optical size. The previous @fontsource-variable/mona-sans 5.3.0 Latin subset has no ss05 in GSUB. This full font does: a -> a.ss05. Keep this feature when replacing/subsetting the asset; CSS computed settings alone do not prove the glyph exists.

fonts.css owns the face for the site and copied exports; do not also import the Fontsource Mona face under the same family name.
