## 核心结论

现有竞品调研比较免费组件、页面区块、完整模板和私有 registry。Oreo 的参考价值在于可安装、可理解、可修改的设计语言，以及组件与完整组合的关系。

## 当时看到了什么

- 免费与付费内容按不同粒度组织，提供 Preview / Usage / Code 与 registry 安装路径。
- 调参工具可以作用于真实设计 token；展示效果工具与产品设计系统解决不同问题。

## 对 Oreo UI 的参考

- 分开组织基础组件、组合模式、完整模板，写清各自责任和安装依赖。
- 把可用示例、用法、共享 motion token 与 Reduce Motion 作为交付内容。
- 价格、内容数、源码缺口和竞品判断保留原日期；不能作为当前产品事实。
