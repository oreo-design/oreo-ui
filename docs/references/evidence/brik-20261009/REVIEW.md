## 参考判断

1. 产品交付可以从单个资产扩展到可调参数、可保存预设的工具。
2. 提示词负责定义或改变工具，结构化控件负责反复微调；实时预览使结果可理解。
3. 用途导航、工具库、主题策展分别服务明确需求、探索效果和寻找方向。
4. 首页用真实工具演示能力；黑白排版框架把色彩让给作品。
5. 对 Voxel Icon 可考虑角度、灯光、背景、配色和转台预览；对产品视频可考虑可复用片头、背景与标题；对 Offloop 可研究可操作产物卡片。这些是建议，不代表已检查当前仓库是否具有相同能力。
