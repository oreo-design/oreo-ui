## 1. 产品结构

两层产品，免费层做漏斗，付费层变现。

| | beui.dev（免费） | pro.beui.dev（Pro） |
|---|---|---|
| 内容 | 74+ 组件 / blocks | ~114 个变体 + 5 套完整模板 |
| 授权 | MIT 开源，824 GitHub stars | 私有仓库 + 私有 registry，源码锁定 |
| 安装 | `shadcn add @beui/xxx` | `shadcn add @beui-pro/xxx` + bearer token |
| 价格 | 免费 | **$149 买断**（founding price，7/27 后 $199）；单套模板 $49–69 |

Pro 的授权模型：一次性付费 → 终身更新 → 无限个人及客户项目 → 源码所有权（copy-paste ownership，文件真实落到用户仓库，非黑盒 npm 包）。

## 3. 技术栈与分发

- React 19 + Next.js + Tailwind CSS v4 + Framer Motion
- 通过 shadcn CLI 的**私有 registry** 分发：
  - `components.json` 中注册两个 registry：公共 `@beui` → `https://beui.dev/r/{name}.json`；私有 `@beui-pro` → `https://pro.beui.dev/r/{name}.json`，带 `Authorization: Bearer` header
  - token 按客户邮箱签发（`BEUI_PRO_TOKEN=beui_live_xxx`），只存 hash，plan 有效期内不过期
  - 三种安装路径：CLI + components.json / CLI 直连带鉴权 URL / 手动拉 JSON 复制文件
  - registry 响应包含 `files`（源文件 + 目标路径）、`dependencies`、`registryDependencies`（依赖的公共 `@beui` primitives）
- 文档站能力：Preview / Usage / Code 三 tab、多包管理器切换的安装命令、全屏预览、刷新预览、⌘K 搜索、明暗切换、What's New 弹窗

### Studio（`/studio`）
一个 WebGL shader 背景合成器：左侧选场景（Hero / Content / Footer CTA）与方向预设（Prismatic drift / Solar veil / Signal field / Mineral tide），中间实时预览，右侧调 Shaders / Looks / Color / Effects / Motion / Compose，最后 "Use background" 导出代码。Shader 库含 Silk、Waves、Contours、Smoke、Flow field、Aurora 等。

**我方判断：不构成竞争壁垒。** 它调的是装饰性背景，属于可替换的锦上添花。我们已有多个工具型 studio（如 oreo avatar），后续直接内置即可，且因为调的是自家设计语言的真实产物，连贯性反而更好。

## 4. 营销手法（需要区分「事实」与「宣称」）

**可验证的事实**：内容量、价格、技术栈、registry 机制、文档站功能。

**不可验证的宣称**：
- "99% Lighthouse score"、"60fps, transform-only"、"28k+ components installed across teams"、"120+ block variants"
- "typed, accessible, responsive" —— 源码锁定，无法验证；无公开测试 / a11y 认证 / 版本化 changelog

**明显的水分**：
- 首页 logo 云（Northwind、Beacon、Quartz、Relay、Stacks、Vellum、Cortex、Mosaic、Helix、Ledger、Pulse、Atlas）与 testimonials（"Maya Chen, FRONTEND LEAD @ NORTHWIND"，配 "REF ARC-8492" 编号）**就是它自家 testimonial / logo-cloud block 的 demo fixture 数据** —— 用组件示例数据充当真实社会证明
- 侧边栏大面积 NEW 徽章 + founding price 倒计时 + savings calculator（可调「从零开发工时 × 时薪」实时算省下多少钱，默认 120h × $100/hr → 省 $11,851）

## 5. 值得学的

1. **分发模式（最高优先级）** —— 「免费 MIT 库建立信任 → 私有 shadcn registry 变现」。技术实现不复杂，一份 `registry.json` + 鉴权端点即可。
2. **「变体」而非「组件」作为产品单位** —— Hero 拆成 7 个各自可预览、可单独安装的变体，内容量与感知价值同时放大。
3. **文档页三 tab：Preview / Usage / Code** —— Usage 是最实用却最常被省略的那个。
4. **把技术承诺写成显式 checklist** —— "shared easing tokens / spring physics / reduced-motion safe / transform-only for 60fps"。抄的不是文案，是这份自检清单。
5. **定价页 savings calculator** —— 俗，但转化率高。

## 6. 不值得学 / 不该跟进的

- 不要跟进 hero / pricing / CTA 这类页面块的广度竞赛。无技术壁垒，Aceternity UI、Magic UI、21st.dev、Tailwind UI 已在同一赛道厮杀。
- 不要用 demo fixture 充当社会证明。
- 不要跟进 Studio 式的装饰性 shader 工具（见 §3）。

## 8. 与 oreo-ui 的定位对照

| | beUI Pro | oreo-ui |
|---|---|---|
| 本质 | 落地页素材超市 | 设计语言的实现范本（design-system reference） |
| 组件粒度 | 页面区块 / 完整模板 | 原子组件（Button、IconButton、Chip、Tag、Shortcut、Avatar、Icon） |
| 使用方式 | 拿走就用，不改 | 作为范本，理解并改 |
| 主张 | "Build less, stand out more" | "own the source, theme via tokens, animate with springs" |

**两个不同的生意，不构成正面竞争。** beUI 刻意绕开的基础控件层（Dialog / Select / Popover / Tooltip / Input / Menu）正是我方的缺口与空位 —— 是空位，不是红海。

### 我方相对优势
`CustomizePanel`（"Make them yours"：暗色切换、圆角滑块 0–999px、spring bounce/duration/tapScale、Phosphor 图标字重）在 design-system 意义上**比 beUI Studio 更正确** —— 它调装饰性背景，我们调真实 design token，且通过注入 `--radius-control` 让整页预览实时重绘。应放大为一等公民功能，而非角落的浮动面板。

### 由本次调研确认的真实技术债
与 beUI 的宣称 checklist 逐条对照后确认（这些是我方客观缺陷，不是竞品对比出来的伪需求）：

1. **无共享 motion token** —— `bounce` / `duration` / `tapScale` 在 Button、IconButton、Chip 中各硬编码一遍
2. **零 reduced-motion 支持** —— 全代码库无 `prefers-reduced-motion`
3. **无分发机制** —— 纯手工 copy 文件夹，无 registry、无 npm 包
4. **无 Usage 文档层** —— 只有 Preview / Code
