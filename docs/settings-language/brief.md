# 可重复的任务输入

基于 Oreo Settings，为 Aster 协作产品实现设置页。

1. Notifications：个人通知开关、通知频率与语言菜单。含中文长描述与长德文选项。选择与开关状态在场景切换后保留。
2. Workspace：权限分组、工作说明编辑器、仅在内容修改后可用的保存操作。保存后显示反馈，支持再次编辑。
3. Integrations：GitHub 已连接、Calendar 授权过期、Documents 未连接。支持等待状态、失败重试、管理详情、断开确认及取消。等待时不重复提交；离开页面不能留下无法结束的请求。
4. 先完成前三项，再加入 Your data：选择 JSON/CSV，准备导出、处理失败、下载可读取的示例文件。尽量复用既有扩展，不修改底层行接口。

保留 Oreo 现有质感。长文字不丢失关键信息，不覆盖操作；窄容器允许重新排布。验证 light/dark、四种背景层级、三种卡片样式、桌面与手机宽度，以及正常和减少动态效果的系统偏好。控件需支持键盘，弹层不应丢失主题或焦点。

对照组：提供固定版本的原始源码与此任务。

实验组：提供相同源码、此任务、README、contract 和检查脚本。不要把本轮现成 recipe 的实现提供给独立生成实验，以免测成答案复述。

记录模型、版本、推理设置、任务输入、起始 commit、完成时间、修改文件、未完成需求、检查失败和人工修正。遇到必须改变基础组件的需求可以扩展，但需要说明关系与证据；禁止通过删除任务或关闭检查制造通过。
